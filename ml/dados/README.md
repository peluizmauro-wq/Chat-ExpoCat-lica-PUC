# Dataset de Machine Learning — Statlog (German Credit Data)

Fonte oficial: UCI Machine Learning Repository, dataset 144.

- Nome: Statlog (German Credit Data)
- Registros: 1.000
- Atributos preditores: 20
- Tarefa: classificação binária de risco (bom/mau risco)
- Sem valores ausentes
- Licença: CC BY 4.0
- DOI: 10.24432/C5NC77
- Página oficial: https://archive.ics.uci.edu/dataset/144/statlog%2Bgerman%2Bcredit%2Bdata

O arquivo `german.data` foi copiado de um espelho público no GitHub que preserva o conteúdo do dataset UCI. A atribuição oficial permanece sendo ao UCI e ao criador Hans Hofmann.

## Uso no projeto ExpoCatólica

O uso é acadêmico e por analogia. O modelo aprende um problema de classificação de risco em uma base pública e conhecida. No Assistente ao Expositor, a previsão é apresentada como uma demonstração de como uma futura base histórica da ExpoCatólica poderia permitir identificar expositores com maior probabilidade de atraso ou pendências.

A previsão não deve ser interpretada como avaliação real de qualquer expositor.
